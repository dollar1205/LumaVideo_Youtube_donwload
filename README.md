# LumaVideo

**LumaVideo** — десктопное приложение для удобного скачивания видео с YouTube. Проект позволяет загружать как обычные длинные ролики, так и короткие видео **YouTube Shorts**, просто вставив ссылку на нужный ролик.

Основная цель проекта — предоставить простой и понятный интерфейс для загрузки доступного видео с YouTube без необходимости вручную работать с консолью или сложными командами.

## Возможности

* 🎬 Скачивание обычных видео с YouTube
* 📱 Полная поддержка YouTube Shorts
* 🔗 Загрузка видео по прямой ссылке
* 📥 Сохранение видео для просмотра офлайн
* 🖥️ Удобное десктопное приложение
* ⚡ Простое управление без необходимости использовать терминал
* 📦 Возможность сборки приложения в готовые исполняемые версии для разных платформ

## Как это работает

Пользователь вставляет ссылку на видео в приложение, после чего LumaVideo обрабатывает URL и получает информацию о доступном ролике. Далее приложение загружает видео и выполняет необходимые действия для его сохранения в выбранном формате.

Поддерживаются стандартные ссылки на YouTube-видео, например:

```text
https://www.youtube.com/watch?v=VIDEO_ID
```

А также ссылки на YouTube Shorts:

```text
https://www.youtube.com/shorts/VIDEO_ID
```

После обработки ссылки пользователь получает возможность сохранить доступный контент для дальнейшего просмотра офлайн.

## Используемые технологии

Проект построен на технологиях, которые позволяют создать полноценное кроссплатформенное десктопное приложение.

### Electron

Для создания графического интерфейса используется **Electron**. Благодаря этому приложение может работать как отдельная программа с собственным окном, интерфейсом и доступом к возможностям операционной системы.

Electron позволяет использовать веб-технологии для разработки интерфейса и одновременно собирать приложение в полноценную программу для настольных операционных систем.

### Node.js

**Node.js** используется для выполнения основной логики приложения, обработки пользовательских действий, работы с файловой системой и взаимодействия между интерфейсом и системной частью программы.

### FFmpeg

Для работы с медиафайлами в проекте используется **FFmpeg**. Он необходим для обработки видео и аудио, а также для выполнения операций, связанных с подготовкой и сохранением загруженного контента.

В проекте также используется статическая версия FFmpeg, что позволяет включать необходимые инструменты для работы с видео непосредственно в сборку приложения.

### Работа с YouTube

LumaVideo обрабатывает ссылки на YouTube и определяет тип видео. Приложение поддерживает:

* обычные видео;
* длинные ролики;
* YouTube Shorts;
* различные форматы стандартных ссылок YouTube.

Это позволяет пользователю просто скопировать ссылку на нужное видео и вставить её в приложение.

## Архитектура приложения

Проект состоит из нескольких основных частей:
